# Ofrivo Mobile

This is the Step 0–3 Flutter application source. It contains the fake-data UI, router, Riverpod state providers, Material 3 theme, feature folders, and the Email + Password Auth/Profile adapter.

The Android platform folder is intentionally generated by the Flutter toolchain rather than hand-written. The current execution environment does not have `flutter`/`dart` on PATH, so `flutter create`, `flutter pub get`, analysis, tests, and APK build are recorded as blocked in `docs/PROJECT_STATUS.md`.

Once a Flutter SDK is available, run from this folder:

```text
flutter create --platforms=android .
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

For a real `ofrivo-dev` connection, pass values at runtime instead of committing them:

```text
flutter run --dart-define=SUPABASE_URL=https://<project-ref>.supabase.co --dart-define=SUPABASE_ANON_KEY=<anon-key> --dart-define=APP_ENV=development
```

If the values are omitted, the app uses local demo mode and does not contact Supabase.
